# Auto Alerta Chile

Crea una aplicación web llamada AutoAlerta, completamente en español y adaptada a Chile.

Debe permitir gestionar un automóvil, sus documentos, vencimientos, mantenciones y gastos.

Incluye estas secciones:

1. Inicio: resumen del vehículo, próximas fechas importantes y gastos.

2. Mi vehículo: marca, modelo, año, patente y kilometraje.

3. Documentos: tipo, fecha de vencimiento y archivo adjunto.

4. Mantenciones: trabajo realizado, fecha, kilometraje y costo.

5. Gastos: combustible, repuestos, reparaciones y otros costos.

6. Historial: lista cronológica de las operaciones registradas.

Permite agregar, editar y eliminar registros. Utiliza pesos chilenos (CLP) y fechas DD/MM/AAAA.

Diseña una interfaz moderna, sencilla y adaptable a teléfonos Android y computadores.

Por ahora, utiliza datos de demostración y almacenamiento local del navegador. No implementes pagos, suscripciones, servicios externos ni funciones que requieran una API de pago. No inventes conexiones con organismos públicos.

Quiero un prototipo funcional para probar gratuitamente, sin contratar servicios ni introducir datos de pago.
